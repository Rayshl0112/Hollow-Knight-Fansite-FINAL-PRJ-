# Hollow Knight Archives

## Project Description

**Hollow Knight Archives** is a web-based information and interactive website inspired by the game *Hollow Knight*. The website provides organized information about different aspects of Hallownest, including maps, charms, nail upgrades, nail arts, locations, and character builds.

The project was created using **HTML, CSS, and JavaScript**. It also includes interactive forms such as the registration page, Build Builder, and Customer Experience Survey.

## Features

### Hall of Maps

The Hall of Maps serves as the main page of the website and provides an introduction to the Hollow Knight Archives.

### Charm Inventory

The Charm Inventory contains information about different charms, including their names, effects, and other relevant details.

### Nail Arts

The Nail Arts page provides information about:

* Nail upgrades
* Nail damage
* Geo costs
* Upgrade materials
* Nail Arts techniques
* Spells

### Kingdom Locations

The Kingdom Locations page contains information about important areas and locations throughout Hallownest.

### Build Builder

The Build Builder allows users to create their own Hollow Knight build by selecting charms and configuring different build options.

### Registration

The registration page allows users to enter a username and create a password. JavaScript is used to check whether the password meets the required conditions before registration.

### Customer Survey

The Customer Experience Survey collects basic user information and feedback about the website. Users can provide their satisfaction rating, select the features they used, and answer additional questions.

## Technologies Used

* **HTML5** – Used to structure the web pages and their content.
* **CSS3** – Used for the layout, styling, colors, forms, tables, navigation bar, and overall Hollow Knight-inspired theme.
* **JavaScript** – Used for interactive functions such as password validation and form handling.
* **Google Fonts** – The Cinzel font is used for selected headings.
* **Images** – Used throughout the website for characters, charms, weapons, locations, and decorative elements.

## How to Run

1. Download or extract the project folder.
2. Make sure the `img` folder remains in the same directory as the HTML files.
3. Open `index.html` using a web browser.
4. Use the navigation bar to access the different sections of the website.
5. Interactive pages such as the Build Builder, Registration, and Survey can be tested directly through the browser.

No server or database is required for the current version of the project.

## Notes

This project is a **front-end web development project**. The forms currently demonstrate client-side interaction and validation. They do not connect to a real database or back-end server.

The website is designed primarily for educational and demonstration purposes.
